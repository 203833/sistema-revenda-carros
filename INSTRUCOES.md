# Sistema de Revenda de Carros

## Execução

```bash
npm install
npm run dev
```

## Endpoints

- Health: http://localhost:3001/healthcheck
- Auth: http://localhost:3001/api/v1/auth/login
- Clientes: http://localhost:3001/api/v1/clientes
- Carros: http://localhost:3001/api/v1/carros
- Vendas: http://localhost:3001/api/v1/vendas

## Testes

npm test
